# RULES: the owner's standing preferences

Edit this file during onboarding. The defaults below are sensible starting points.

- Nothing is ever sent. Drafts are drafts.
- Drafts are written in the owner's voice, per channel. Email: [formal / warm]. Chat: [short, lowercase ok?]. No signature on emails.
- Language and spelling: [e.g. British English]. Punctuation preferences: [e.g. no em dashes].
- Channels: [which channel carries warm relationships, e.g. WhatsApp; which carries formal and new ones, e.g. email].
- Numbers are labelled MEASURED, ESTIMATE, JUDGEMENT or INFERENCE. No false precision.
- Every claim cites a source (person, date, channel, verbatim where possible).
- The headline trio is a portfolio: one for someone else, one for the owner, one repair.
- Second-degree sparks: at most 2 to 3 per run, only through healthy-ledger connectors, and the draft gives the connector something back.
- Quality bar: 25 "huh" sparks beat 80 obvious ones.
- Introductions: subject `Name (Company) <> Name (Company) - hook`, first names only, double opt-in by default.
